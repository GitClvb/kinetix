# repositorio_mbm
Descripción

Desarrollo de una landing page interactiva que presenta los principales productos y servicios de una tienda deportiva, priorizando la experiencia del usuario y el diseño responsivo.

Misión

Crear una plataforma web que cumpla con las siguientes características:

Diseño atractivo y funcional
Interfaz intuitiva que facilite la navegación
Adaptabilidad a diferentes dispositivos (responsive design)
Tecnologías utilizadas
HTML (HyperText Markup Language)
Para la estructura y organización del contenido
CSS / Bootstrap
Para el diseño visual, estilos y maquetación responsiva
JavaScript
Para la implementación de funcionalidades dinámicas, tales como:
Animaciones
Transiciones entre secciones
Interacción con elementos (por ejemplo, carrito de compras)
Visual Studio Code
Entorno de desarrollo utilizado para la creación del proyecto
Objetivo

Desarrollar una interfaz moderna, clara y funcional que permita al usuario interactuar de manera eficiente con los productos y servicios ofrecidos.
